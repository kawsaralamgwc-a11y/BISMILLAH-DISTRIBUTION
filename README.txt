BDC PRO v1.2 — Bismillah Distribution Center
=============================================

বাংলা
-----
১. zip ফাইলটি ফোন বা কম্পিউটারে আনজিপ করুন।
২. "index.html" ফাইলটি Chrome-এ খুলুন। (ফোনে: Files অ্যাপ → index.html → Chrome দিয়ে খুলুন)
৩. প্রথমবার নাম, ফোন, দোকানের নাম ও পাসওয়ার্ড দিয়ে অ্যাকাউন্ট খুলুন।
৪. ভাষা বদলাতে: মেনু খুলে ওপরের "English / বাংলা" বোতাম, অথবা লগইন পর্দা ও সেটিংস থেকে।

নতুন (v1.2)
- ক্রয়, বিক্রয়, ক্রয় অর্ডার ও বিক্রয় অর্ডার পেজে বামে পণ্যের তালিকা, ডানে ইনভয়েস।
- পণ্যে চাপ দিলে ইনভয়েসে যোগ হয়; + / − দিয়ে পরিমাণ বদলান। সার্চ বক্সে বারকোড স্ক্যান করে Enter দিলে পণ্য সরাসরি যোগ হয়।

জরুরি কথা
- ডেটা এই ব্রাউজারেই জমা থাকে (অফলাইনে চলে, সার্ভারে কিছু যায় না)।
- ব্রাউজারের ডেটা মুছলে বা অন্য ব্রাউজারে খুললে ডেটা দেখা যাবে না।
- তাই নিয়মিত সেটিংস → ব্যাকআপ থেকে "কপি" করে লেখাটি নিরাপদে রাখুন।
- একই ফাইল সবসময় একই জায়গা (একই ফোল্ডার/একই ব্রাউজার) থেকে খুলুন।
- পাসওয়ার্ড শুধু অ্যাপের স্ক্রিন লক করে, এটি এনক্রিপশন নয়।
- বাংলা ফন্ট ইন্টারনেট ছাড়া ফোনের নিজস্ব বাংলা ফন্টে দেখা যায়।

ফাইলের তালিকা
- index.html  : পুরো অ্যাপ (লোগো ভেতরেই আছে)
- manifest.json + icons/ : হোম স্ক্রিনে যোগ করার আইকন (ওয়েবসাইট হিসেবে হোস্ট করলে কাজ করে)
- icons/logo.png : বড় সাইজের গোল লোগো (১০২৪px)

English
-------
1. Unzip the archive on your phone or computer.
2. Open "index.html" in Chrome. (On a phone: Files app -> index.html -> open with Chrome)
3. On first launch, create your account (name, phone, store name, password).
4. Switch language with the "English / বাংলা" button at the top of the menu, on the login screen, or in Settings.

New in v1.2
- Purchase, Sales, Purchase Order and Sales Order pages: product list on the left, invoice on the right.
- Tap a product to add it; use + / - to change quantity. Scan a barcode into the search box and press Enter to add it directly.

Important
- Data is stored in this browser only (works offline; nothing is sent to a server).
- Clearing browser data, or opening the file in a different browser, will not show your data.
- Copy a backup regularly from Settings -> Backup and keep the text somewhere safe.
- Always open the same file from the same place in the same browser.
- The password only locks the app screen; it is not encryption.
- Without internet the app uses your phone's own Bangla font.

Files
- index.html  : the whole app (logo is embedded)
- manifest.json + icons/ : home-screen icon files (used when the app is hosted as a website)
- icons/logo.png : large round logo (1024px)
